RANTING EVENT HALL RSVP WEBSITE

Cara guna dalam VS Code:

1. Extract ZIP ini.
2. Buka folder ranting_event_hall_website dalam VS Code.
3. Install extension "Live Server" dalam VS Code.
4. Right click index.html.
5. Tekan "Open with Live Server".

File penting:
- index.html = struktur website
- style.css = design website
- script.js = fungsi RSVP WhatsApp dan music
- assets/ranting-logo.png = logo
- assets/music.mp3 = letak lagu sendiri di sini, kalau nak guna background music

WAJIB EDIT:
Buka script.js dan tukar:
const whatsappNumber = "60123456789";

Contoh:
const whatsappNumber = "60175556666";

Pastikan guna format 60, bukan 0.
Contoh betul: 60123456789
Contoh salah: 0123456789

Untuk lagu:
Letakkan file MP3 dalam folder assets dan namakan:
music.mp3

Cadangan lagu:
- soft piano instrumental
- nature ambient piano
- elegant acoustic instrumental
- luxury corporate background music
